# Introduction

> [!note] Définition — Chat
> L'agent qui écrit le code.
> Ask et Ctrl+I ne s'appellent pas chat.

## Objectifs

- Copilot, entre l'éditeur et le modèle.
- Le code qui reste : commentaires, complétion, Ctrl+I.
- L'agent : tests unitaires et POC.
- Ce qui part dans une requête.
- Le moment où part une instruction, un agent, un skill.
